## Project 01 - E-commerce Web Testing | SauceDemo


This project was created to practice manual software testing on the SauceDemo e-commerce web application.
The main goal was to apply the QA process to a web application: understand the functionality, design test cases, execute them, compare expected and actual results, collect evidence, and report defects.

# Application Under Test

Application: SauceDemo

Type: E-commerce web application

Website: https://www.saucedemo.com/

The application simulates an online shopping experience including login, product browsing, shopping cart and checkout.
