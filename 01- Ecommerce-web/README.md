## Project 01 - E-commerce Web Testing | SauceDemo


This project was created to practice manual software testing on the SauceDemo e-commerce web application.
The main goal was to apply the QA process to a web application: understand the functionality, design test cases, execute them, compare expected and actual results, collect evidence, and report defects.

# Application Under Test

Application: SauceDemo

Type: E-commerce web application

Website: https://www.saucedemo.com/

The application simulates an online shopping experience including login, product browsing, shopping cart and checkout.

# Objectives

- Create structured manual test cases.
- Execute functional tests.
- Validate positive and negative scenarios.
- Test UI behavior.
- Test cart and checkout functionality.
- Perform browser/device compatibility checks.
- Identify and document defects.
- Organize evidence and results

# Test Coverage

### 40 manual test cases covering:
- Login
- Invalid login attempts
- Product listing and information
- Add to cart
- Shopping cart behavior
- Checkout
- Form validation
- Navigation
- UI behavior
- Browser/device compatibility
  
### Test Case Format
- Each case includes:
- Test Case ID
- Title
- Objective
- Preconditions
- Test Data
- Steps
- Expected Result
- Actual Result
- Status
- Evidence
- Related defect, when applicable
