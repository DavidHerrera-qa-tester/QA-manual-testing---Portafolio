# BUG-001 — Users cannot increase the quantity of a product

## Bug Information

| Field | Details |
|---|---|
| Bug ID | BUG-001 |
| Type | Functional |
| Category | Shopping Cart |
| Severity | Medium |
| Priority | Medium |
| Status | Open |
| Environment | SauceDemo |
| Reported Date | 2026-08-20 |

---

## Summary

The shopping cart does not provide a way for users to increase the quantity of an existing product. When a product is added to the cart, the user cannot select or modify the desired quantity.

---

## Preconditions

- User is logged into SauceDemo.
- User is on the Products page.

---

## Steps to Reproduce

1. Log in to SauceDemo.
2. Select any product.
3. Add the product to the shopping cart.
4. Open the shopping cart.
5. Attempt to change the product quantity from 1 to 2 or more units.

---

## Expected Result

The shopping cart should allow the user to modify the quantity of the selected product, for example from 1 to 2 or 3 units.

---

## Actual Result

The shopping cart does not provide a quantity selector or another mechanism to increase the quantity of the selected product.

The user must add the product through another purchase flow instead of being able to modify the quantity directly in the shopping cart.

---

## Severity

**Medium**

The issue does not prevent the user from purchasing a product, but it limits an important e-commerce shopping cart functionality.

---

## Priority

**Medium**

The issue should be addressed because users may reasonably expect to purchase multiple units of the same product from the shopping cart.

---

## Additional Notes

This issue affects the usability of the shopping cart when a customer wants to purchase multiple units of the same product.
