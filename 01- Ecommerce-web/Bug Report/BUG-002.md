# BUG-002 — Product images become distorted on iPad Pro and iPad Mini viewports

## Bug Information

| Field | Details |
|---|---|
| Bug ID | BUG-002 |
| Type | Compatibility |
| Category | Responsive Design / UI |
| Severity | Medium |
| Priority | Medium |
| Status | Open |
| Environment | SauceDemo |
| Browser | Brave 1.93.137 (64-bit) |
| Testing Method | Browser DevTools Device Emulation |
| Reported Date | 2026-08-20 |

---

## Summary

Product images become visually distorted when SauceDemo is displayed using tablet-sized viewports.

The images do not consistently maintain their original aspect ratio when the viewport is simulated as an iPad Pro or iPad Mini, causing some images to appear wider or vertically stretched.

This negatively affects the visual consistency and overall user experience of the application on tablet-sized screens.

---

## Preconditions

- SauceDemo is accessible in the browser.
- Brave browser is installed.
- Browser Developer Tools are available.
- Device emulation is enabled.

---

## Steps to Reproduce

1. Open SauceDemo in Brave Browser.
2. Open Developer Tools.
3. Enable Device Toolbar / Responsive Device Emulation.
4. Select the iPad Pro device preset.
5. Navigate to the Products page.
6. Observe the product images.
7. Repeat the test using the iPad Mini device preset.
8. Compare the product images with their appearance on the desktop viewport.

---

## Expected Result

Product images should maintain their original aspect ratio when the viewport changes.

Images should resize proportionally without becoming horizontally wider or vertically stretched.

The visual proportions of the products should remain consistent across supported tablet viewport sizes.

---

## Actual Result

When using the iPad Pro and iPad Mini viewport simulations, some product images become visually distorted.

Depending on the viewport, the images appear wider or vertically stretched, indicating that their original aspect ratio is not being consistently preserved.

This results in an inconsistent visual presentation and negatively affects the user experience on tablet-sized screens.
