# BUG-003 — API accepts check-in date after check-out date

## Related Test Case
`TC-API-010`

## Environment
- API: Restful-Booker
- Method: `POST`
- Endpoint: `/booking`
- Tool: Postman
- Execution date: 2026-08-24

## Severity
High

## Priority
High

## Preconditions
The API is available.

## Steps to Reproduce
1. Open TC-API-010 in Postman.
2. Send `POST /booking`.
3. Set `checkin` to a date later than `checkout`.
4. Send the request.
5. Observe the response.

## Expected Result
The API should reject the invalid date range with `400 Bad Request`.

## Actual Result
The API returns `200 OK` and accepts the request.

## Impact
The API permits a logically invalid booking period, indicating missing business-rule validation.
