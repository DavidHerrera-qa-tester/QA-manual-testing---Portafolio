# BUG-001 — Missing required firstname returns 500 Internal Server Error

## Related Test Case
`TC-API-007`

## Environment
- API: Restful-Booker
- Method: `POST`
- Endpoint: `/booking`
- Tool: Postman
- Execution date: 2026-08-24

## Severity
High

## Priority
High

## Preconditions
The API is available.

## Steps to Reproduce
1. Open TC-API-007 in Postman.
2. Send `POST /booking`.
3. Remove the `firstname` field from the request body.
4. Send the request.
5. Observe the response.

## Expected Result
The API should reject the request with `400 Bad Request` and handle the missing required field as a controlled validation error.

## Actual Result
The API returns `500 Internal Server Error`.

Response body:
`Internal Server Error`

## Impact
A client-side validation problem is handled as an internal server error instead of a controlled validation response.

## Status
Open
