# BUG-002 — Invalid date is accepted and produces invalid date values

## Related Test Case
`TC-API-009`

## Environment
- API: Restful-Booker
- Method: `POST`
- Endpoint: `/booking`
- Tool: Postman
- Execution date: 2026-08-24

## Severity
High

## Priority
High

## Preconditions
The API is available.

## Steps to Reproduce
1. Open TC-API-009 in Postman.
2. Send `POST /booking`.
3. Provide an invalid or malformed booking date.
4. Send the request.
5. Inspect the response status and returned date.

## Expected Result
The API should reject the invalid date with `400 Bad Request`.

## Actual Result
The API returns `200 OK` and produces the invalid value `NaN-undefined-NaN`.

## Impact
Invalid date input is accepted and transformed into unusable date data.

## Status
Open
