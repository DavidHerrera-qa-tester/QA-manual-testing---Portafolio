# BUG-004 — Zero or negative price causes 500 Internal Server Error

## Related Test Case
`TC-API-012`

## Environment
- API: Restful-Booker
- Method: `POST`
- Endpoint: `/booking`
- Tool: Postman
- Execution date: 2026-08-24

## Severity
High

## Priority
High

## Preconditions
The API is available.

## Steps to Reproduce
1. Open TC-API-012 in Postman.
2. Send `POST /booking`.
3. Set `totalprice` to `0` or a negative value.
4. Send the request.
5. Observe the response.

## Expected Result
The API should reject the invalid price with `400 Bad Request`.

## Actual Result
The API returns `500 Internal Server Error`.

Response body:
`Internal Server Error`

## Impact
Invalid price input triggers an internal server error instead of a controlled validation response.
