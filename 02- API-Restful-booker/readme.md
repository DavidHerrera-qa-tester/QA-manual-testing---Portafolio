# Poyecto 02 - API Testing | RestFull-Booker

## Proyect Overview

This project was created to practice API testing with Postman using the Restful-Booker hotel booking API.

The goal was to learn how a QA tester can validate requests and responses, create positive and negative test cases, automate checks with assertions, and report defects using clear evidence.

## Application Under Test

API: Restful-Booker

Type: REST API for a hotel booking system

Base URL: https://restful-booker.herokuapp.com

## Objectives
- Practice REST API fundamentals.
- Understand HTTP methods and status codes.
- Create and execute API test cases in Postman.
- Validate status codes and JSON responses.
- Write automated assertions.
- Perform positive and negative testing.
- Validate input data and basic business rules.
- Use Postman variables and simple request chaining.
- Identify and document API defects.

## Tools & Technologies
- Postman
- REST / HTTP
- JSON
- JavaScript (Postman test scripts)
