

## Objective
Validate the integrity and consistency of data stored in `Northwind_Portfolio` using SQL queries designed from a QA perspective.

## Scope

### In scope
- Customer data
- Product data
- Order data
- Order detail data
- Table relationships
- Aggregations
- Null/missing values
- Invalid numeric and business-rule values

### Out of scope
- Performance/load testing
- Security penetration testing
- Database administration
- Backup/recovery testing

## Test Types
- Positive testing
- Negative testing
- Boundary testing
- Data validation
- Data completeness
- Referential integrity
- Relational integrity

## Environment
- Database: `Northwind_Portfolio`
- Engine: Microsoft SQL Server
- Tool: SSMS
